# 로컬 근거 전달 실험

로컬 모델이 자료를 읽고 메인 모델에 짧은 답과 원문 근거를 전달하는 실험이다.
운영 어댑터와 전역 지침은 바꾸지 않는다. 합성 자료만 사용한다.

세 조건을 같은 Claude·Codex CLI와 읽기 도구로 비교한다.

| 조건 | 처리 방식 |
|---|---|
| direct | 메인 모델이 검색하고 필요한 원문을 읽는다. |
| tool | 메인이 한 번 위임한 뒤 짧은 답과 근거를 받는다. |
| preflight | 로컬 분석을 먼저 끝내고 그 결과를 첫 입력에 붙인다. |

`compact.py`는 로컬이 지정한 줄을 파일에서 다시 읽고 해시로 변경 여부를 확인한다.
메인에는 상대 경로, 줄 번호, 실제 원문과 답 초안만 전달한다. 원문 일치가 곧 답의
정확성을 뜻하지는 않는다. 메인이 의미를 확인하고 필요한 경우 추가로 읽는다.
근거의 형식 오류, 내용 누락, 크기 제한과 로컬 실패는 숨기지 않고 직접 처리로 넘긴다.

입력은 네 종류의 기존 합성 과제다. 두 변형씩 총 8건을 세 조건과 두 클라이언트로
실행한다. 코드 과제의 두 변형은 정답이 같고 방해 파일만 다르므로 독립적인 실무
사례 8건으로 해석하면 안 된다. 예비 실행은 본 측정에서 제외한다.

```sh
python3 -m unittest discover -s token_savings -p 'test_savings.py' -v
python3 token_savings/run.py --setup
python3 token_savings/run.py --suite
python3 token_savings/analyze.py
```

실행 전 vault에 별도 상태 폴더와 CLI 구독 인증 프로필을 준비하고 `state` 심링크로
연결한다. 인증 자료를 프로젝트에 복사하지 않는다. fixture 경로에는 운영 로컬
어댑터가 비밀 경로로 차단하는 단어를 쓰지 않는다. 현재 `fixtures` 연결은
`local_compare/fixtures/savings`를 가리킨다. 자료와 보고서는 공개 복사에서 제외한다.

총 클라우드 토큰은 호출마다 집계된 입력과 출력의 합이다. 캐시 입력을 포함한 총량과
캐시 입력을 뺀 양을 함께 기록한다. 구독 한도나 결제 금액으로 환산하지 않는다.
사전 분석의 시간에는 로컬 실행도 포함하며 파일 응답 캐시는 사용하지 않는다.
공유 서버의 KV 캐시와 클라우드 캐시는 비우지 않고 호출 순서와 서버 점유 상태를 기록한다.
실험을 준비하고 결과를 정리한 이 대화의 토큰은 개별 과제 사용량에 포함되지 않는다.

원본 결과, 도구 기록, 숨겨진 채점표, 인증 자료는 vault에 남는다. 소스 코드만 공개
복사 검사 대상이다. 새 실험을 시작할 때는 새 상태 폴더를 사용해야 한다.
